# StudyKAD
A responsive multi-section website built for students to browse and join virtual study rooms for various academic and technical topics.
## Sections & Features
 **Header & Navigation:** Responsive top bar featuring the site logo and navigation links.
 **Hero Section:** Engaging main heading, supporting description, call-to-action button, and a hero image.
 **Study Rooms (Features):** Interactive cards showcasing active rooms, designed using CSS Grid with smooth hover effects.
 **About Section:** A clean two-column layout for desktop that stacks vertically on mobile devices.
 **Contact & Footer:** Fully structured contact form with proper inputs and labels, alongside contact info and social links.
## Technologies Used
 **HTML5:** Semantic elements, proper heading hierarchy, and meaningful image alt text.
 **CSS3:** External stylesheet, CSS variables  :root, box model, and various CSS selectors.
 **Responsive Design:** A combination of Flexbox, CSS Grid, media queries, and relative units to ensure full compatibility across desktops, tablets, and mobile screens.
 **Animations & Transitions:** Custom keyframe animations and smooth CSS transitions for interactive elements.
